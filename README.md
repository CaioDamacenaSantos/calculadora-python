# calculadora-python
Calculadora simples em Python com tratamento de erros, funções, loops e suporte para 6 operações matemáticas."


Uma aplicação interativa de linha de comando (CLI) desenvolvida em Python para realizar cálculos matemáticos básicos com foco na validação contínua de dados de entrada do usuário.

## Funcionalidades

    Operações Suportadas:

        +  Adição
        -  Subtração
        *  Multiplicação
        ÷  Divisão (com validação para evitar divisão por zero)
        ** Potenciação
        √  Raiz Quadrada (com validação contra números negativos)

    *Tratamento de Erros Integrado:

       Validação de entrada para evitar fechamento do programa por erros de digitação (letras em vez de números).
    O programa solicita novamente a digitação apenas no campo onde ocorreu o erro, preservando o fluxo.

       Navegação Contínua: Permite realizar múltiplos cálculos sem a necessidade de reiniciar o algoritmo.

Versão do Python Utilizada

      Python  3.14.3



# Como Executar





Pré-requisitos
  
       Ter o Python 3 instalado em sua máquina.

       
       

## Passo a passo

  -Clone este repositório:
  
        git clone https://github.com/CaioDamacenaSantos/calculadora-python.git
  
  
  -Acesse a pasta do projeto:
  
        cd calculadora-python
  
  
  -Execute o programa:
  
        python calculadora.py
